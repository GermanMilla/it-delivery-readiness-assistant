# Team Context

This file defines the default deliveery tools for the agile team. If a project or user provides different tools, use the project-specific tools instead of these defaults

## Delivery tools

- Backlog management tool: Azure DevOps
- Ticketing system: ServiceNow
- Diagramming tool: Visio
- Repository tool: Azure DevOps Repos
- CI/CD tools: Azure DevOps
- Deployment platform: Azure Kubernetes Service (AKS)

## Tool Adaptation Rules

When providing delivery-readiness guidance, adapt terminology and recommendations to the selected tools.
