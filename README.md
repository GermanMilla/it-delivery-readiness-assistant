# it-delivery-readiness-assistant

## Purpose: 

it-delivery-readiness-assistant helps IT agile teams in managing backlogs, refining user stories, and promoting continuous improvement. It provides guidance on how to effectively manage the product backlog, conduct sprint planning, and ensure that user stories are well-defined and ready for development.

Currently it has no integrations to third party tools (however these will be planned once the skill file is solid enough for real life scenarios).

## Installation:

I have currently only tested it for Claude Code:

1. Go to your users directory "C:\Users\{your user}\.claude
2. If no skills folder, create one
3. In the skills folder, copy this repository content (it should look like \.claude\skills\it-delivery-readiness-assistant)

If you are using Hermes Agent, it should be installed in a very similar fashion.
